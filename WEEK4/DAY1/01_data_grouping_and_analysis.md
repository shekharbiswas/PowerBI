# 📊 Grouping, clustering, and statistical analysis (Module 4 – Part 1)

Welcome to **Week 4, Day 1**. We're staying with Capital Bikeshare, but the dataset has grown — we now have ridership data stretching from 2019 through June 2026, plus a second data source to bring in. In this session, we'll use **analytical tools in Power BI** to discover trends, clusters, and summaries hidden in a much longer history than we've worked with before.

We'll learn how to group data for comparison, use **binning and histograms**, apply **clustering techniques**, and explore basic **statistical summaries** — and this time, those summaries span years, not weeks.

- How clustering can uncover hidden patterns
- Differences between continuous vs. categorical axes
- How to apply statistical summaries across a long time span, not just a single period

<br>

## 🖼️ Key concepts

| Concept                   | Description                                                                 |
|---------------------------|-----------------------------------------------------------------------------|
| **Grouping/binning**      | Categorize continuous data into fixed intervals                            |
| **Histogram**             | Visualize frequency of data across bins                                    |
| **Clustering**            | Identify similar records based on features                                 |
| **Categorical axes**      | Used to group data into labeled categories                                 |
| **Statistical summary**   | Summarize count, min, max, average, median, standard deviation — and how these shift year over year |
