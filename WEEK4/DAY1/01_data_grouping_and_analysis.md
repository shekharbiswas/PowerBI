# 📊 Grouping, clustering, and statistical analysis (Module 4 – Part 1)

Welcome to **Week 4, Day 1**. In this session, you'll dive into **analytical tools in Power BI** to discover trends, clusters, and summaries hidden in your data.

You’ll learn how to group data for comparison, use **binning and histograms**, apply **clustering techniques**, and explore basic **statistical summaries** that help describe and interpret your visuals.

<br>

## 🖼️ Key concepts

| Concept                   | Description                                                                 |
|---------------------------|-----------------------------------------------------------------------------|
| **Grouping/binning**      | Categorize continuous data into fixed intervals                            |
| **Histogram**             | Visualize frequency of data across bins                                    |
| **Clustering**            | Identify similar records based on features                                 |
| **Categorical axes**      | Used to group data into labeled categories                                 |
| **Statistical summary**   | Summarize count, min, max, average, median, standard deviation              |

## 🛠️ Practice task: Group and cluster your data

### Goal:
Explore a dataset and apply grouping and clustering to find patterns.

### Steps:
1. Load a dataset like `Sales or Customer Orders` into Power BI  
2. Use **binning** on a continuous field (e.g., purchase amount)  
3. Create a **histogram** from the binned data  
4. Apply **clustering** to segment customers by total spend or region  
5. Add a card or table with a **statistical summary**  
6. Save your work as `PatternAnalysis_Grouping.pbix`
