# 🔮 Forecasting and AI-powered visuals (Module 4 – Part 2)

Welcome to Part 2 of Day 1. Now that we've explored how to group and analyze data patterns across several years of Capital Bikeshare history, it's time to step into **predictive analytics and AI**.

## 🖼️ Key concepts

| Tool/Visual              | Purpose                                                                     |
|--------------------------|------------------------------------------------------------------------------|
| **Forecasting**          | Predict future values using trends in time series data                      |
| **Reference lines**      | Add markers for goals, targets, or statistical thresholds                   |
| **Error bars**           | Show uncertainty or confidence intervals in visuals                         |
| **Key Influencers**      | Discover which fields impact a selected value the most                     |
| **Decomposition Tree**   | Drill down into metrics to understand **why** a change occurred             |
| **Q&A Visual**           | Enter natural language questions to generate charts automatically           |

## 🛠️ Practice task: Explain a trend with AI tools

### Goal:
Use forecasting and AI visuals to tell the story behind the data — including the parts of the story a plain trend line doesn't explain on its own.

### Steps:
1. Reopen the grouped and clustered report from earlier (`PatternAnalysis_Grouping.pbix`)
2. Create a **forecasting line** for a time-based metric (e.g., revenue or units sold)
3. Add a **reference line** for a target value
4. Apply **error bars** to visualize variability
5. Insert a **Key Influencers** visual to analyze drivers of change
6. Use a **Decomposition Tree** to break down the metric by category, region, or time period
7. Try a **Q&A visual** to ask "what drives high revenue?"
8. If the forecast doesn't look right, don't just note it and move on — dig into why, using the tools above
9. Save as `PatternAnalysis_AI.pbix`
