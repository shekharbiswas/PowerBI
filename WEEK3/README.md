# 📊 Overview: Visual Reports, Dashboards & Sharing Insights

Welcome to **Week 3** of your Power BI journey with **Dataskools**.  
This week, you'll **transform raw data into visual stories** that drive business decisions.

You’ll learn how to build reports and dashboards, apply best practices for accessibility and interactivity, and **publish insights** to share with stakeholders. You’ll also get hands-on with **performance tuning**, exploring how to optimize visuals and DAX calculations like a pro.

## 🗓️ Weekly Breakdown

| Day | Topic                                | Focus Area                                                                |
|-----|--------------------------------------|----------------------------------------------------------------------------|
| 1   | **Foundations of Visual Reporting**   | Learn what visualizations are and build your first Power BI report         |
| 2   | **Chart Types & KPIs**                | Explore chart types, KPIs, and when to use each for storytelling           |
| 3   | **Accessibility & Interactivity**     | Make reports more usable with formatting, slicers, buttons, and bookmarks |
| 4   | **Dashboards, Sharing & Optimization**| Build dashboards, share reports, and tune for speed with performance tools |

<br>

## 🎯 Learning Objectives

By the end of this week, you will be able to:

- Build effective Power BI reports using a range of visualizations  
- Apply accessibility features to improve report usability  
- Create interactive experiences with drillthrough, slicers, and bookmarks  
- Build dashboards and publish your insights to the Power BI service  
- Tune visual and DAX performance for faster, smoother reporting  

<br>

## 📈 Difficulty snapshot – Week 3

| 🧠 Topic Area                      | ⚙️ Difficulty | 💬 What to Expect                                                       |
|----------------------------------|---------------|-------------------------------------------------------------------------|
| 📊 Visualizing data               | 🟢 Easy        | Drag-and-drop visuals with basic customization                         |
| ⚙️ Formatting & accessibility     | 🟡 Medium      | Requires attention to detail and user experience                       |
| 🧠 Interactivity & navigation     | 🟡 Medium      | Involves logical flow and multiple components like slicers/bookmarks   |
| 📁 Dashboards & publishing        | 🟡 Medium      | Easy to create, but best practices matter for usability                |
| 🧪 Performance tuning with DAX    | 🔴 Hard        | Includes variables, context, and analyzer tools — key for PL-300 prep  |

> 💡 **Tip:** Start with storytelling, not just charting. Ask: *What does my audience need to know — and why does it matter?*
