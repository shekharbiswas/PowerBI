Today marks your entry into the **visualization layer** of Power BI — where raw data meets storytelling.

In this session, you'll explore **what visualizations are**, learn about **common types**, and build your **very first business report** using Power BI's Report Editor. These skills are foundational to presenting insights clearly and effectively to your audience.

## 🖼️ Key concepts

| Concept                    | Description                                                                 |
|----------------------------|-----------------------------------------------------------------------------|
| **Visualization**         | A visual representation of your data, like a bar chart or KPI               |
| **Business report types** | Operational, analytical, strategic — each serves a different audience       |
| **Report Editor**         | The Power BI interface for building and editing report pages                 |
| **Visualizations pane**   | Where you choose chart types and customize their appearance                  |
| **Fields pane**           | Drag-and-drop dimensions and measures from your dataset                      |
| **Canvas**                | The main workspace to design your report layout                             |

<br>

## 🛠️ Practice task: Create your first report

### Goal:
Build a basic sales report using **table visualizations** and simple formatting.

### Steps:
1. Load a sample dataset (like `SalesData.xlsx`) into Power BI  
2. Use a **table** to show product names and sales values  
3. Add a **title** and adjust font size/colors for readability  
4. Explore other visuals in the pane — bar, column, pie  
5. Save your report as `Week3_Day1_SalesReport.pbix`
