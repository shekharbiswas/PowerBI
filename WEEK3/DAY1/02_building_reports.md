## 🖼️ Key concepts

| Feature                  | Description                                                                 |
|--------------------------|-----------------------------------------------------------------------------|
| **Chart switching**      | Easily convert one chart type to another to better suit the data            |
| **Cards & KPIs**         | Simple visuals for showing a single summary metric                          |
| **Visual layout**        | Align, size, and structure visuals for clarity and balance                  |
| **Pinning**              | Save key visuals to dashboards for quick access and monitoring              |
| **Sales report (final)** | Combine table + chart + KPI + title into a cohesive, informative layout     |

## 🛠️ Practice task: Finalize your sales report

### Goal:
Refine your first report with visuals, layout, and dashboard-ready output.

### Steps:
1. Reopen your `Week3_Day1_SalesReport.pbix`  
2. Add a **bar chart** for product category vs. total sales  
3. Insert a **card** visual for total revenue  
4. Align visuals on canvas and apply consistent sizing and theme  
5. Pin one visual to a **new dashboard** (Power BI Service only)  
6. Save as `SalesReport_Final.pbix`
