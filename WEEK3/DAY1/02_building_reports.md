# 📊 Building reports with Power BI editor

Now that you’ve explored what visualizations are, it’s time to **level up your report-building skills**.

In this session, you’ll get familiar with the **Power BI Report Editor interface**, learn how to use the **visualizations pane**, and explore how different chart types behave. You’ll also practice using **tables** and pinning visuals to dashboards.

## 🧠 What you’ll learn

- How to use the Power BI Report Editor and canvas  
- How to switch between visual types  
- When and how to use **tables** effectively  
- How to **pin visuals** to dashboards  
- The role of **basic layout** in user-friendly reports  

<br>

## 🖼️ Key concepts

| Concept                  | Description                                                              |
|--------------------------|--------------------------------------------------------------------------|
| **Visualizations pane** | Menu of charts and visuals you can drag onto the canvas                 |
| **Table visual**        | A grid format for displaying raw or grouped data                        |
| **Canvas**              | The layout area where visuals are placed and arranged                   |
| **Pinning**             | Adding a visual from a report directly to a Power BI dashboard          |
| **Sales report**        | A practical scenario for applying layout and formatting techniques       |

<br>

## 🛠️ Practice task: Enhance your sales report

### Goal:
Refine the report you started earlier and explore new visuals.

### Steps:
1. Reopen your `Week3_Day1_SalesReport.pbix` file  
2. Add a **clustered bar chart** showing product category vs. total sales  
3. Insert a **card** visual to show total revenue  
4. Change the report **layout**: align, resize, and apply a theme  
5. Pin your favorite visual to a **new dashboard** (if using Power BI Service)  
6. Save your report as `SalesReport_Final.pbix`
