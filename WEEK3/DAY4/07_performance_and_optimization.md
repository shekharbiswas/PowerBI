## 🖼️ Key concepts

| Tool/Concept              | Description                                                                 |
|---------------------------|-----------------------------------------------------------------------------|
| **Performance Analyzer**  | Tool for identifying slow visuals and bottlenecks in reports                |
| **DAX optimization**      | Writing efficient measures with fewer nested functions                      |
| **Variables in DAX**      | Storing intermediate values for reuse and better performance                |
| **DAX context**           | Controlling row and filter context to get accurate results                  |
| **Troubleshooting**       | Using step-by-step testing and the formula bar to debug calculations        |

## 🛠️ Practice task: Speed up your report

### Goal:
Use tools and techniques to diagnose and improve report speed.

### Steps:
1. Open your `SalesReport_Interactive.pbix`  
2. Launch **Performance Analyzer** (View tab → Performance Analyzer)  
3. Record performance and find the slowest visual  
4. Rewrite any inefficient DAX measures using **variables**  
5. Try different visual types or filters to compare impact  
6. Save as `SalesReport_Optimized.pbix`
