# 🧭 Adding interactivity to reports (Module 2 – Part 2)

In the second half of Day 2, you’ll move beyond static visuals and start building **interactive reports**.

You'll explore how to give your users more control by using **slicers, filters, buttons, and drillthrough pages**. These tools allow you to create a dynamic experience where users can slice and dice the data themselves.

## 🖼️ Key concepts

| Feature                  | Description                                                                |
|--------------------------|----------------------------------------------------------------------------|
| **Slicer**               | A visual filter that lets users select values dynamically                  |
| **Drillthrough**         | A page that shows detailed data for selected items                         |
| **Button**               | Custom clickable elements to guide navigation                              |
| **Bookmark**             | A saved view of a report page that you can link to via buttons             |
| **Grouping/layering**    | Arranging visuals to improve structure and navigation                      |

<br>

## 🛠️ Practice task: Interactive report design

### Goal:
Add interactivity features to your accessible sales report.

### Steps:
1. Open your `SalesReport_Accessible.pbix`  
2. Add a **slicer** to filter data by region or month  
3. Create a **drillthrough page** for product-level details  
4. Add **buttons** to switch between views or pages  
5. Create **bookmarks** for different report states  
6. Group and layer visuals for a clean layout  
7. Save as `SalesReport_Interactive.pbix`
