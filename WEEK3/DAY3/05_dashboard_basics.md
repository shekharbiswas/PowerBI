# 🧱 Dashboard design fundamentals (Module 3 – Part 1)

Welcome to **Day 3**! Today, you begin **Module 3**, which focuses on building dashboards — a key tool for business leaders and operational teams.

You’ll learn what dashboards are, how they differ from reports, and how to build one by pinning visuals to the Power BI Service. Dashboards let users **view insights at a glance** and are great for monitoring key metrics.

<br>

## 🖼️ Key concepts

| Concept                 | Description                                                               |
|-------------------------|---------------------------------------------------------------------------|
| **Dashboard**           | A read-only canvas that shows pinned visuals from multiple reports        |
| **Pinned visuals**      | Report elements saved to a dashboard for quick access                     |
| **Workspace**           | A Power BI Service area to organize and publish reports/dashboards        |
| **Glanceable insights** | KPIs and summaries you can quickly interpret without drilling in          |

<br>

## 🛠️ Practice task: Build your first dashboard

### Goal:
Turn your interactive sales report into a lightweight dashboard.

### Steps:
1. Publish your `SalesReport_Interactive.pbix` to Power BI Service  
2. Open the published report and pin key visuals (e.g., card, chart)  
3. Create a **new dashboard** and name it `Sales Dashboard`  
4. Add a title, test responsiveness, and arrange layout  
5. Share or take a screenshot of your completed dashboard
