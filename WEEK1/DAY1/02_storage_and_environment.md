# ⚙️ Setting Up Your Environment + Understanding Storage Modes

Welcome to the second half of Day 1! Now that you know what a data source is, it’s time to **get hands-on** by setting up your Power BI environment and learning how the tool stores data under the hood.

---

## 🎯 Goal for This Session

By the end of this session, you'll know:
- How to set up your Power BI workspace
- How to connect a flat file like Excel
- What storage modes (Import, DirectQuery, Dual) mean and when to use them

---

## 🧠 Why This Matters

Think of Power BI as a smart assistant. But before it can help you make decisions, you need to:
1. **Invite the data in** (set up the source)
2. **Tell it how to behave** (choose how it stores and reads the data)

Understanding storage modes isn’t just a tech skill — it’s a **performance decision**. If your report is slow or not updating in real time, the storage mode is often the reason.

> ⚠️ Many junior analysts skip this step — but **smart analysts know how to choose the right mode** based on business needs.
