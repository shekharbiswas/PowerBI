# 📅 Day 1: Exploring Data Sources in Power BI

Welcome to Day 1 of your Power BI journey. Today is all about **where your data comes from** and how Power BI connects to those sources.

---

## 🎯 What You'll Learn

- The importance of connecting data from multiple sources
- Differences between flat, structured, and unstructured data
- How Power BI uses connectors to link with various systems
- What storage modes are and how they affect performance
- How triggers and actions automate data workflows

---

## 📘 Concepts To Explore

### Combining Data Sources
Learn how bringing data together from different systems can help uncover new business insights that wouldn't be visible from a single source.

### Flat vs. Structured Data
Understand the difference between a simple flat file like Excel and a structured source like a database. Recognize how each type fits into real-world reporting scenarios.

### Storage Modes in Power BI
Explore the different ways Power BI can store or access data: whether it imports everything, queries it live, or uses a hybrid mode — and what that means for speed and flexibility.

### Connectors, Triggers, and Actions
Discover how Power BI connects to other apps and services using connectors, and how you can automate updates or workflows using triggers and actions.
