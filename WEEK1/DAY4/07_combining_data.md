# 🔗 Combining Data with Append, Merge & Joins

You’ve cleaned your data — now it’s time to bring different datasets together.

Today, you’ll learn how to **combine data tables** using Power BI’s powerful “append” and “merge” tools, and how **joins** let you match information across sources.

<br>

## 🎯 Goal for this session

Understand the difference between appending and merging tables, and know how to apply different join types in Power BI.

<br>

## 🧠 Why this matters

Real-world data often lives in **multiple tables**:
- Customers in one file 📋
- Orders in another 💰
- Product info in a third 🛍️

Knowing how to **bring these together accurately** is a core data analyst skill.

Be intentional about which columns you match on and always **check your results** before moving forward.
