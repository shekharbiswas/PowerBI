# 🛠️ Power Query Basics & Applied Steps

Welcome to Day 3 and the start of **Module 2**: Transforming Data in Power BI.  
This is where things get really hands-on — you'll start reshaping data and preparing it for analysis.

<br>

## 🎯 Goal for This Session

Get familiar with Power Query’s interface and learn how transformation steps are applied to your data.

<br>

## 🧠 Why This Matters

Power Query is like your **data cleaning workbench**.  
Think of it as a recipe — each time you transform your data, Power BI records that step in the background, so it can repeat it automatically every time the data updates.

<br>

## 🧰 You’ll Learn How To:

- Navigate Power Query Editor  
- Understand the **Applied Steps** list  
- Transform columns and rows  
- Explore different data types

> 🧼 Power Query helps you clean and reshape your data **without writing code**.
