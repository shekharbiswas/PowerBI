# 📘 Overview: Profiling, Loading & Final ETL Project

Welcome to **Week 2** of your Power BI learning journey at **Dataskools**.  
This week, you’ll shift from transforming data to making it **reliable, scalable, and ready for reporting**.

You’ll explore **data profiling**, learn how to handle **bad or missing data**, and get hands-on with **advanced ETL techniques** like reference queries and the Advanced Editor. Then you’ll apply all your skills in a **final project** to prepare multiple data sources — just like you would on a real job.

<br>

## 🗓️ Weekly Breakdown

| Day | Topic                             | Focus Area                                                              |
|-----|-----------------------------------|--------------------------------------------------------------------------|
| 1   | **Data Profiling & the ETL Pipeline** | Understand the full ETL workflow, staging, and profiling for data quality |
| 2   | **Power Query Best Practices**    | Learn reference queries, dataflows, helper queries, and performance tips  |
| 3   | **Advanced Querying Techniques**  | Apply parameters, use the Advanced Editor, and manage file settings       |
| 4   | **Final Project + Course Assessment** | Bring it all together in your final Power BI project and reflect on progress |

<br>

## 🎯 Learning Objectives

By the end of this week, you will be able to:

- Profile and assess the quality of incoming data  
- Use best practices for working with Power Query and large datasets  
- Apply reference queries and build reusable dataflows  
- Modify queries using parameters and the Advanced Editor  
- Complete a mini-project to prepare and combine multiple sources  
- Reflect on your learning and get ready for visualizing data next week
