# 🔁 Reference Queries & Using Dataflows

In this session, you'll learn how to create **modular, reusable Power BI queries** using reference queries and how to **scale your work** with dataflows.

<br>

## 🎯 Goal for this session

Understand how to simplify and scale your ETL process by using **reference queries** and **Power BI dataflows**.

<br>

## 🧠 Why This Matters

Imagine copying and pasting the same query logic into five different reports.  
Now imagine you find a bug. Yep — you'd need to fix it five times. 😩

**Reference queries** help you avoid this. You write it once and reuse it across multiple steps or reports.

And with **dataflows**, you can:
- Centralize data logic across teams  
- Improve performance  
- Reuse transformations across workspaces

> 🧠 Smart analysts avoid repetition — and build with reuse in mind.

## 💡 Real-World Use Case

> Imagine you’re building 3 dashboards from the same customer table.  
> Rather than loading and cleaning that table 3 times, use a reference query once — and connect it to each report. Fast, consistent, and smart.
