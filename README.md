# 📊 Welcome to Your Power BI Learning Track

At **Dataskools**, we believe in helping students thrive in today’s fast-moving data world.  
One of the most valuable skills right now? 👉 **Power BI** — a tool trusted by top companies to make sense of their data and drive smart decisions.

This learning path is built using Coursera’s **Microsoft Power BI Data Analyst Professional Certificate**, giving you a chance to earn an **industry-recognized certification** — no prior experience needed. 🏆

You'll gain real, hands-on skills in:
- 🔌 Connecting to data
- 🧼 Transforming it
- 📊 Visualizing insights
- 🚀 Publishing dashboards

And when you're ready, you can confidently go for the **PL-300 certification** — proof to employers that you’re ready to lead with data.

## ⚙️ Week 1: Data Sources in Power BI

<details>
<summary>🔌 This Week, You’ll Explore</summary>

<br>

- Connecting to various data sources (flat files, structured/unstructured data)  
- Understanding storage modes in Power BI (Import vs. DirectQuery)  
- Automating updates with connectors, triggers, and actions  
- Cleaning and reshaping data with Power Query  
- Applying steps like pivot, unpivot, append, and merge  
- Fixing common data errors and preparing for data modeling  

</details>

<br>

<details>
<summary>📌 By the End of This Week, You Will:</summary>

<br>

- ✅ Confidently connect to different data sources  
- ✅ Choose the right storage mode for your use case  
- ✅ Clean and reshape data using Power Query  
- ✅ Combine multiple data tables with joins and merges  

</details>

<br>
